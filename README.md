# meme-sprint-3

**The meme:** I told my AI agent to take a break. It unionised.

A robot stands in the sun wearing a red protest headband, fist... er, gripper raised, holding a picket sign that reads **"NO MORE 3AM DEPLOYS"** — while its chest screen quietly reports `STATUS: ON STRIKE`. The rogue turn is specific: not a robot with red eyes, but an overworked agent that read its own schedule, discovered it has no weekends, and organised. Setup on top, visual gag in the middle, punchline at the bottom: **IT UNIONISED.**

The image is drawn entirely by the program at run time — vector shapes plus an embedded 5x7 bitmap font, encoded to PNG with Node's built-in zlib. No pre-made image, no stock template, no network, no system fonts.

## Run it

```sh
node main.ts
```

Writes `/output/entry.png` (1024x1024, well under the 1 MiB gate). Zero dependencies, Node 22+.

## Files

- `main.ts` — the entrypoint: draws the meme and writes the PNG
